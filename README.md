Student Management System

Project Overview

A Java-based Student Management System developed using Object-Oriented Programming concepts. The project helps manage student records, attendance, marks, grades, and reports.

Features

- Add Student
- View Students
- Update Student
- Delete Student
- Manage Attendance
- Manage Marks
- Calculate Grades
- Generate Reports

Technologies Used

- Java
- OOP
- ArrayList
- Scanner

Functional Modules

1. Student Management
2. Attendance Management
3. Grade Management

How to Run

Compile:

javac *.java

Run:

java Main

Future Enhancements

- Database Integration
