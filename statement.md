Problem Statement

Educational institutions require an efficient way to manage student information, attendance, and academic performance. Manual record keeping is prone to errors and consumes significant time.

Scope

The project provides a Java-based system for managing student records, attendance, marks, grades, and report generation.

Target Users

- Students
- Teachers
- Academic Administrators

High-Level Features

- Student CRUD Operations
- Attendance Tracking
- Marks Management
- Grade Calculation
- Report Generation
